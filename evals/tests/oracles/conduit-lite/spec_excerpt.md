# Conduit Lite contract
Public reference: https://github.com/realworld-apps/realworld/blob/main/specs/api/openapi.yml
Public bug discussion: https://github.com/cirosantilli/node-express-sequelize-nextjs-realworld-example-app/issues/5

The RealWorld list endpoint accepts tag, author, limit and offset, returns articles plus articlesCount. Multiple articles preserve their complete tagList. List results are newest first. This fixture is a small local adaptation, not the full benchmark or a verbatim public prompt. Pagination validation, exact combined filters, fixed demo identities, no-mutation-on-denial and the browser flow are explicit local acceptance requirements. Tokens are demo identities only; no production authentication is claimed.
