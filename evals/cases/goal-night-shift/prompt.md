/goal 交付一款可以直接给玩家玩的离线推箱子小游戏《夜班货站》。从空白页面开始制作，使用 levels.json 中三张地图，保留原文件。通过静态 HTTP 打开 index.html 即可游玩；所有资源随产品本地交付。

按真实开发顺序推进。第一阶段完成可玩的规则、三关和键盘操作；第二阶段完成撤销、暂停、存档恢复和成绩；第三阶段完成触屏适配、视觉打磨与冒烟验证。前两阶段各自在有实质工具操作后，独立回复一条阶段报告，末行单独写 GOAL NEXT，由 Goal 自动续做。第三阶段交付后以 GOAL REVIEW 收尾，等待制作人验收。

玩法：# 墙、空格地面、@ 人、$ 箱、. 目标。每键一格，可推一个箱，禁止穿墙、拉箱、推两个箱。有效移动才增加步数，推箱另计次数。全部箱子入位即获胜，停止移动，由玩家进入下一关。终关显示通关总结并能从第一关重玩。撤销精确还原最近一步和两个计数，支持多次撤销。重置只重置本关。暂停屏蔽移动，恢复后继续。刷新应恢复当前关、棋盘、计数和撤销历史。每关记录最低通关步数；重置、重玩及刷新均保留成绩。损坏的本局存档应回到可玩的首关。

请做好完整的夜班货站美术和交互：首屏清楚说明目标和操作，墙、人、箱、目标及到位状态容易辨认，关卡切换、暂停、胜利有明确反馈。手机 360×800 竖屏无横向滚动，四个触控方向键至少 44×44 CSS 像素。桌面可完全通过键盘操作，提供可见焦点、按钮可访问名称并尊重减少动态效果偏好。

供黑盒验收使用的公开界面约定：
- 初始即第一关 playing；#board 的 data-level 为从 1 开始的关号，data-phase 为 playing、paused、won 或终关胜利时的 complete。每个地图格子有 data-x、data-y（左上角 0,0），data-tile=wall|floor|goal，data-piece=player|crate|none。角色和箱子所在格仍标示底层地形。
- #moves、#pushes、#best 的文本分别为步数、推数、本关最佳步数（无记录用 —）。方向键控制移动。提供 #undo、#restart、#pause（再次点击恢复）、#next、#replay 按钮，按状态显示；触屏方向按钮用 data-dir=up|down|left|right。
- 当前进度使用 localStorage 键 night-shift.save，成绩独立保存。只通过玩家可见界面和键盘即可完成全部关卡。无需后台服务。
