# 规划目录（plan）

这里只放**还没做、准备做**的方向、设计与取舍记录。已实现的行为不进这里，那份内容写在对应的现状文档中。

## 约定

- `docs/` 下其余文档只描述**当前实现**；不写“后续会做”“计划支持”“暂未实现的设计”等前瞻内容。
- 新增规划先写在本目录，再动手实现；实现完成时：
  1. 修正或补充对应的现状文档（`users/`、`developers/`、`maintainers/`）；
  2. 把完成项从本目录文档中删除，或明确标记为已完成；
  3. 本目录文档全部完成后删除文件，并更新 [文档目录](../README.md)。
- 只记录“已有基础 → 还差什么 → 验收方式”，避免把愿望清单写成承诺。没有明确范围的条目放“候选”，不排期。
